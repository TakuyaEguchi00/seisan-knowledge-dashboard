GitHub で外部 URL 化（確実なやり方: Public ミニリポ）

  1. 親リポジトリの share/public-dashboard-site/ の中身すべてを、新規の Public リポジトリのルートにコピーして push（index.html と .github/workflows/deploy-github-pages.yml がルートに来る形）。
  2. その Public リポで Settings → Pages → Source を GitHub Actions にする。
  3. Actions の「Deploy GitHub Pages」成功後、表示される https://<ユーザー名>.github.io/<公開リポ名>/ を共有する（このファイルを index.html にしているのでトップで開きます）。
  4. 図解を更新したら scripts/sync-public-dashboard.ps1 で share/public-dashboard-site/index.html を差し替え、公開リポへ再 push。

親リポジトリだけで Pages を試す場合（参考）

Private のままだと無料 Organization では 404 になりやすいです。手順の詳細は docs/PAGES-SETUP.md。

404 が消えないとき: リポジトリが Private だと無料プランでは github.io の公開サイトが出ません。上の「Public ミニリポ」か Netlify 等を使ってください。

プレビューだけ素早く見せたいとき

GitHub の raw URL では HTML はレンダリングされない。Pages が無い場合は htmlpreview 等のプレビューサービスを利用するか、ファイルを zip で渡す。
